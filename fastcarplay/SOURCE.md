# FastCarPlay integration

This integration is built from `niellun/FastCarPlay` commit
`f483456318344710d2890fc7ee0d67608892dea2` under GPL-3.0.

Audi MMI changes the embedded background, status colours/text, and compiles for
the Raspberry Pi 5 Cortex-A76. The runtime configuration is `settings.txt`.
The upstream source is available at https://github.com/niellun/FastCarPlay.
